# Customer Churn Analysis & Prediction Model

## 📌 Executive Summary
Customer churn is a critical business metric indicating the percentage of subscribers who discontinue their service. This repository presents an end-to-end data analysis and predictive pipeline designed to identify high-risk churn customers using machine learning techniques.

## 🚀 Key Features
- **Data Pipeline:** Automated generation and cleaning of customer demographic and subscription datasets.
- **Predictive Modeling:** Implemented a Random Forest Classifier to identify patterns leading to customer attrition.
- **Business Insights:** Pinpoints key churn drivers, such as contract terms (Month-to-Month) and payment methods.

## 🛠️ Tech Stack
- **Python:** Data processing & Machine Learning (`pandas`, `scikit-learn`, `numpy`)
- **Git & GitHub:** Version control and collaboration.
